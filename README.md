# ☁️ Cloud Monitoring Dashboard

A professional Full Stack Cloud Monitoring Dashboard built using React, Node.js, Express, Axios, and Recharts.

This project simulates a real-time cloud infrastructure monitoring platform similar to AWS CloudWatch, Datadog, or Grafana.

---

# 🚀 Features

## Frontend

* Modern dark dashboard UI
* Responsive design
* Sidebar navigation
* Real-time monitoring cards
* CPU analytics chart
* Alerts management table
* AWS / Azure / GCP monitoring panels

## Backend

* Node.js + Express server
* REST APIs
* Dynamic monitoring data
* Real-time simulation updates

## Monitoring Metrics

* CPU Usage
* Memory Usage
* Disk Usage
* Network Traffic
* Active Alerts
* Server Status

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/cloud-monitoring-dashboard.git
```

## 2. Install Frontend Dependencies

```bash
cd frontend
npm install
```

## 3. Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

# ▶️ Run Frontend

```bash
cd frontend
npm run dev
```

---

# ▶️ Run Backend

```bash
cd backend
npm run dev
```
